Privacy & Authorized Use

NISKALA hanya boleh digunakan pada perangkat dan jaringan milik sendiri atau dengan izin tertulis.

Data Cloud Sync

Cloud Sync mengirim data hasil pengujian ke endpoint hosting yang dikonfigurasi oleh pemilik perangkat. Jangan mengirim kredensial atau data pribadi tanpa dasar izin yang jelas.

Data di dashboard

Data disimpan di folder server yang dikonfigurasi pemilik hosting. Lindungi akses dashboard dan API key. Jangan membagikan API key atau file rahasia.

Batasan penggunaan

  • Dilarang mengganggu jaringan publik.
  • Dilarang menguji perangkat pihak lain tanpa otorisasi.
  • Gunakan lingkungan lab terisolasi untuk pengujian aktif.
