Authorized use

NISKALA hanya boleh digunakan pada perangkat dan jaringan milik sendiri atau yang memiliki izin tertulis. Gunakan lab terisolasi untuk pengujian aktif.

Data & Cloud Sync

Cloud Sync mengirim ringkasan hasil pengujian ke endpoint hosting yang dikonfigurasi pemilik perangkat.

Data pengujianProbe, Karma, BLE, dan hasil modul yang dipilih.
Lokasi penyimpananServer hosting yang Anda konfigurasi sendiri.
Kontrol pemilikAPI key dan dashboard harus dijaga pemilik.

Jangan mengirim password, API key, atau data pribadi tanpa dasar izin dan kebutuhan yang jelas. Gunakan `secrets.h` lokal dan jangan memasukkannya ke Git.

Keamanan operasional

  • Gunakan token Web Remote jika fitur autentikasi diaktifkan.
  • Lindungi API key Cloud Sync.
  • Batasi akses dashboard dan folder data.
  • Hapus data pengujian yang tidak lagi diperlukan.

Batasan penggunaan

Dilarang mengganggu jaringan publik, menguji perangkat pihak lain tanpa izin, atau menggunakan data untuk merugikan orang lain.
  • ESP32 hanya mendukung WiFi 2.4 GHz.
  • PMF/WPA3 dapat memblokir management frame tertentu.
  • WiFi dan BLE berbagi satu radio.
  • Hasil pengujian dipengaruhi kondisi radio, driver, dan perangkat target.
